# Workforce Attrition Analysis – Palo Alto Networks

## 📌 Project Overview
This project analyzes employee attrition patterns at Palo Alto Networks to identify high-risk areas and key factors influencing employee turnover.

---

## 🎯 Objectives
- Calculate overall attrition rate
- Identify high attrition departments and roles
- Analyze demographic and workload impact
- Build an interactive dashboard for insights

---

## 📊 Dataset
The dataset includes:
- Employee demographics (Age, Gender, Education)
- Job details (Department, Role, Salary)
- Work factors (Overtime, Travel, Satisfaction)
- Attrition status (0 = No, 1 = Yes)

---

## 🔍 Key Insights
- Overall Attrition Rate: ~16%
- Sales department has highest attrition
- Overtime employees have ~3x higher attrition
- Early-career employees show higher exit rates
